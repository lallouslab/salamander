Getting Started with UnFAT Plugin

With the UnFAT plugin, you can browse images of floppy disks, hard drives, and USB sticks that contain a FAT file system (FAT12, FAT16, or FAT32), and extract files and directories from them. UnFAT archive files have the .IMA extension.

See the Archiver section in Using Plugins for a description of basic work with plugin archivers.
