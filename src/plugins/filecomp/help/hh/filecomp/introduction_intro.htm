Getting Started with File Comparator Plugin

The File Comparator plugin allows you to visually compare text and binary files, showing you the differences side-by-side. It can also show detailed differences, highlighting not only lines with differences, but also the specific added, changed, and deleted characters.

See the Menu Extension section in Using Plugins for a description of basic operations with menu extensions.
