Sally: Dialog Boxes

Sally Task List

Use this dialog box to break or terminate an unresponsive Sally task.

Dialog Box Options

List of running Sally tasks
Contains a list of all Sally tasks. The current task is marked with "current process".
Highlight
Flashes the main window of the selected Sally task.
Break
Breaks the selected Sally task and invokes its Bug Report dialog.
Terminate
Terminates the selected Sally task.
Refresh
Refreshes the list of running Sally tasks.
