Sally: Customizing Sally

Configuring Sally

The configuration contains settings from the Configuration dialog, the main window position, panel widths and current directories, and other options. To configure Sally, open the Options menu and choose Configuration. Then select the page you want in the tree, change the options you want, and click OK.

Saving the configuration

To save the configuration to the registry, use the Options/Save Configuration command. By default, the configuration is saved automatically when you close Sally. To change this behavior, open General configuration page and clear the Save configuration on exit check box.

Exporting the configuration

You can export Sally's configuration to a file. Choose the Options/Export Configuration command. If you save the configuration to a file named config.reg and place this file in the installation directory (near sally.exe) or, on Vista or later, in the application data directory (typically C:\Users\<user>\AppData\Roaming\Sally), the configuration will be imported from this file to the registry before loading Sally's configuration from the registry.

The configuration file is a simple text document; you can easily edit it with any text editor. Administrators can change this file to suit their needs, then place it in a network installation of Salamander so Salamander is ready to use in a network environment.

When exporting configuration, you can choose whether to clear the registry key that stores the configuration (this takes place before importing keys and values). Use this option if you want to use the exported configuration file to fully replace the current configuration in the registry. If you just want to change some values and leave the rest of the current configuration in the registry unchanged, clear this option. All keys and values from the file overwrite the current values in the registry. If you delete some values from the configuration file, you'll avoid overwriting the users' values (users will have their own values - it's useful for window positions and other nonessential settings).

Importing the configuration

You can import Sally's configuration from a file. To get such a file, see previous section about exporting configuration. You can import configuration from another computer or revert to a previously exported configuration to undo unwanted changes.

Importing the configuration is quite simple. Just find the configuration file and open it (use the Enter key or double-click it). It should open in Registry Editor. When Registry Editor asks whether you want to add information from the file to the registry, you should close all running instances of Sally. This prevents the newly imported configuration from being overwritten by the automatic save performed when Sally exits. When Sally is not running, click Yes in the Registry Editor message box. The configuration is then imported from the file into the registry.

Remarks

Sally's configuration is stored in the Windows Registry: 'HKEY_CURRENT_USER\Software\Sally\X', where X is Open Salamander's version.
