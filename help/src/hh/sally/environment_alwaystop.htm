Sally: Working with Windows and Panels

Setting Window Always on Top

If you want the main window of Sally to stay above nearly all other application windows, select the Always on Top item on the main window's window menu (click the icon in the upper left corner of Sally's main window or use Alt+Space). When this item is selected, the main window becomes a topmost window and can be overlapped only by other topmost windows.

To toggle the Window Always on Top option:

Menu:Options/Always on Top
Window menu:Always on Top
